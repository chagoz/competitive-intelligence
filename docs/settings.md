# User settings

Every value an operator can set, its default, and where it lives.
Status: "locked" = decided, "open" = still being settled.

## Method behaviour

| Setting | Default | Lives in | Status |
|---|---|---|---|
| Recency window | 12 months | analysis-rules §2.1 | locked |
| Watch-list item window | first run uses the recency window; after, the run's cadence; an inline prompt window overrides | analysis-rules §2.1 | locked |
| Bets reading scope | top tier, extendable to all tiers | analysis-rules §2.8 | locked |
| "What's for us" line | off | weekly-digest + slack template | locked |
| Lost-deal pull | on when a source is configured | analysis-rules §8 + configuration.md | open (source types) |
| Qualifying-loss category match | fixed exact-match | analysis-rules §1 | open |
| Role word | "operator" (convention, not per-operator) | all skills | locked |
